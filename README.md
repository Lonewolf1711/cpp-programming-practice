# C++ Programming Practice

A collection of C++ programs for practicing core concepts, data structures,
algorithms, and the Standard Template Library (STL).

## Structure
- `day-01/` - Hello World, input/output basics
- `day-02/` - ...

## Build and Run
```
g++ -std=c++17 -Wall -Wextra <file>.cpp -o <name>
./<name>
```

## Tools
- Language: C++17
- Compiler: g++ (MinGW-w64)
- Editor: Visual Studio Code
